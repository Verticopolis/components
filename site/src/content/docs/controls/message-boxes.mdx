A message box (`messageBoxView` from `windows/messageBox`) is a title, an optional icon before it, a paragraph or two and a row of buttons. Every message box opens in one modal dialog (`ModalShell` from `windows/uiModal`). It blocks the page until it is answered, as a 1995 message box did. Esc, the ✕ and a press on the backdrop close it. A notice under the title bar says what went wrong without closing the box.
